# Memory Match Game

Memory Match Game adalah game web kasual yang dibuat menggunakan HTML, CSS, dan Vanilla JavaScript.

🎃[pampukin.netlify.app](https://pampukin.netlify.app/)

🐛[shngrc.netlify.app](https://shngrc.netlify.app)


## 🚀 Cara Menjalankan

1. Clone repo ini
   ```bash
   git clone https://github.com/horengoding/Memory-card-game.git
   ```
2. Masuk ke folder project
   ```bash
   cd Memory-card-game/Memory-Game
   ```
3. Buka `index.html` langsung di browser, atau jalankan local server:
   ```bash
   npx http-server .
   ```

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid, CSS Variables, Media Query)
- Vanilla JavaScript
